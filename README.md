# ✝本質✝ OVERFLOW —偏差値60の教室から—

> 偏差値60の教室から漏れ出す✝本質✝を、寺地の太マジックで✝を刻んで確定させる60秒。偽物に刻むと三重の「は？」が飛んで全部台無しになる反射スコアアタック。

## 遊び方

### 10秒で理解
1. **漏れてくるカード**を見分ける  
2. **✝本質✝なら「刻む」**、**偽物なら「は？」で弾く**  
3. 画面最下段（最も漏れ切る寸前）のカードが**自動で狙われる** — 狙うストレス0

### 操作（2ボタンのみ）

| 操作 | 方法 |
|---|---|
| **刻む（✝）** | カードをタップ / 左クリック / `Z` / `←` |
| **は？（弾く）** | カードを下スワイプ / 右クリック / `X` / `→` |
| **OVERFLOW** | 画面下中央 ✝ボタン / `Space`（ゲージ満タンで手動発動） |

- チュートリアルはアニメ付き2.2秒（スキップ可）。文章説明なし。
- 全演出はタップでスキップ可能。

### 見分け方（0.3秒で識別）

| 種別 | 見た目 | 正解 |
|---|---|---|
| **✝本質✝** | 白紙・金の発光・角に✝ | 刻む |
| **亜✝本質✝** | 発光なし・灰色の縁・文字が滲む | は？ |
| **ノイズ** | 赤茶スクショ風・角丸・硬い影 | は？ |
| **フェイカツ** | 金の光はあるが✝が上下反転 / フォント違う | は？ |
| **コーンスープ缶** | オレンジ缶・湯気 | 刻む → +3.0s |
| **結婚指輪** | 銀の輪・光反射 | 刻む → 高得点 |
| **原✝本質✝** | 巨大カード・耐久3 | 3回刻む |
| **シュレディンガー札** | 2枚が半透明で重なる | 刻む＝観測（成功2倍/失敗大ダメージ） |

色だけでなく形・✝の有無・縁の質感でも判別可能（色覚多様性対応）。

### タイマー / スコア

- 制限時間 **60.00秒**（0.01秒表示、残り10秒で赤化＋脈動）
- ✝成功 **+0.15s** / は？成功 **+0.10s** / 誤爆 **-1.50s** / 本質取りこぼし **-0.50s**
- スコア: `✝成功 100×倍率` / `は？成功 60×倍率` / レア 500〜1500
- 倍率: `1.0 + floor(combo/10)×0.5` 上限 **×8**（零スキルで一時×10）
- 誤爆でコンボ0・倍率リセット・画面全体に「は？」スタンプ（0.35秒、入力は止めない）

### 偏差値（スコア表示）

```
偏差値 = 60 + 40 × (1 - exp(-score / 45000))
```

| 偏差値 | ランク |
|---|---|
| 60〜64 | 非✝本質✝ |
| 65〜69 | 亜✝本質✝ |
| 70〜74 | ✝本質✝ |
| 75〜84 | 原✝本質✝ |
| 85 | 数理零ライン（専用演出） |
| 86以上 | 前-原✝本質✝ |
| 100 | 隠しランク「✝」（全画面✝） |

### OVERFLOWゲージ（フィーバー）

- ✝/は？成功で溜まる、誤爆で30%減。**満タンで任意のタイミングで手動発動**
- 発動中 **7秒**: 全カードが✝本質✝化（連打で得点）、倍率+2、タイマー停止
- 壁が3段階で剥がれる: ①地層断面 ②等高線浮上 ③夜空と桜 → 1秒で逆再生

## 演出フェーズ尺（実測）

| フェーズ | 尺 | 内容 |
|---|---|---|
| Phase1 タイトル | 0s（静止）- 無限待機 | 教室、蛍光灯明滅、黒板等高線、床目地から✝が漏れる、自販機売切 |
| Phase2 開始カウント | **1.6s** | 照明落ち → 紙に3・2・1をマジックで書く → 床が割れて光噴出、BGMイン |
| Phase3 本編 | **60s** | 密度カーブ 0-15易→15-30中→30-45難→45-60狂、5秒ごとに引っかけ配置 |
| Phase4 OVERFLOW | **7s** | 任意発動、壁3段階剥離、ラジアルブルーム、衝撃波3層、カメラ寄り、光条、紙吹雪はピーク1回 |
| Phase5 リザルト | **約6s**（スキップ可） | カード落下0.4s → 配信終了 → 寺地が偏差値を手書き → カウンターロール → 称号押印 → 背景切替 → 掲示板レス → 三重の「は？」でオチ |

**1プレイ総所要時間: 約68〜74秒（本編60s + 前後約8〜14s）** — 3回連続で遊びたくなる尺。

## サウンド

- すべてWeb Audio APIリアルタイム合成（音声ファイルなし）
- ペンが紙を擦る音（フィルタードノイズ）、紙めくれ、✝確定チャイム（コンボで半音上昇8段）、誤爆「は？」（下降ノイズ＋フォルマント風バンドパス）、コーンスープのプシュッ音、OVERFLOW上昇トーン→爆発（ベース＋ノイズ）、カウンタチクチク、勝利ファンファーレ
- BGMも合成4音ミニマルループ（教室＝乾いたピアノ風 / OVERFLOW＝厚いパッド＋キック）、残り10秒でテンポ+8%、OVERFLOW中はローパスを開く
- 初回タップでAudioContext初期化、右上ミュートトグル、音無しでも遊べる

## エンジニアリング

```
index.html
src/
  config.js   … 全チューニング値集約
  audio.js    … WebAudio合成
  game.js     … 状態機械・カードプール・スコア・スキル・演出
  main.js     … 起動・データ読込・UI配線
styles/
  main.css    … レスポンシブ・演出・アウトライン
data/
  quotes.json … 125件（honshitsu 70件）
  characters.json … 17キャラ
assets/ ... 立ち絵・アイコン（ルートとicon/配下）
```

- 描画レイヤー分離: 背景（静的CSS）/ ゲーム（DOM）/ エフェクト（Canvas加算）/ UI（DOM）
- カード・粒子はオブジェクトプールで再利用、毎フレームGCゼロ
- 状態機械: `TITLE → TUTORIAL → COUNTDOWN → PLAY → OVERFLOW → TIMEUP → RESULT → TITLE`
- `deltaTime`基準、可変フレームレート対応、タブ復帰時クランプ
- `prefers-reduced-motion`尊重（シェイク停止・粒子1/4・フラッシュ弱化）
- モバイル縦(375×667)〜PCワイドまでレスポンシブ、セーフエリア対応、ダブルタップズーム無効化
- `?debug=1` でヒットボックス・fps・即ランク操作パネル

## アセット追加手順

1. **立ち絵**: `chr_*.png`（透過）をリポジトリ直下に配置 → `data/characters.json`の`tachi`フィールドに追加 → テーマカラー`color`を同時設定。見つからない場合は自動でシルエット＋名前プレートにフォールバック（コンソールに一覧出力）。
2. **アイコン**: `icon/*.jpg`を配置 → `characters.json`の`icon`にパス記載。
3. **語録**: `data/quotes.json`に`{text(全角24字以内), type, speaker, source, weight, unlocked}`を追加。`type`は`honshitsu/a_honshitsu/noise/fake_katsu/rare`のいずれか。`weight`が出現重み。
