# ✝本質✝ OVERFLOW ―偏差値60の教室から―

制限時間60秒のスコアアタック型ブラウザゲーム。
原作『偏差値60の教室から✝本質✝が漏れ出している件について』(`gensaku.txt`)の語録カードを、
寺地の太マジックで**✝を刻む**か、三重の**は？**で弾くか。反射と気持ちよさで殴る60秒。

GitHub Pages でそのまま動く。ビルド不要・ES Modules・相対パスのみ。

## 遊び方

- 操作は2つだけ。判定対象は**最も画面下のカード**(▼マーク)を自動ターゲット。
  - **刻む（✝）**: カードをタップ / `Z` / `←` … ✝本質✝・レア用
  - **は？（弾く）**: カードを下スワイプ / `X` / `→` … 亜✝本質✝・ノイズ・フェイカツ用
- **OVERFLOW**: ゲージ満タンでボタン/`Space`で任意発動。7秒間フィーバー（全カード✝化・倍率+2・タイマー停止）。
- 勝也の等高線モード中（残り30秒〜5秒間）は**ドラッグでなぞり斬り**可能。
- チュートリアルは4秒アニメのみ。`?debug=1` でデバッグパネル。

## スコア計算式

```
✝成功  = 100 × 倍率 (+0.15秒)
は？成功 =  60 × 倍率 (+0.10秒)
レア    = 500〜1500 (コーン800/指輪1500/英語800/原1000)
誤爆    = コンボ0・倍率リセット・−1.50秒・「は？」スタンプ
取りこぼし(本質系のみ) = −0.50秒・コンボ断

倍率 = 1.0 + floor(コンボ/10) × 0.5 (+OVERFLOW中は+2)、上限×8（零バフ中×10）
砂糖スロー中は得点×1.5

偏差値 = 60 + 40 × (1 − exp(−score / 45000))
```

## アセット追加手順

1. 立ち絵PNG（透過・`_no_bg`推奨）をリポジトリ直下に置く。
2. アイコンJPGを `icon/` に置く（52px丸抜き表示）。
3. `data/characters.json` に1エントリ追加:
   `id / name / portrait / icon / color(テーマ色・リムライト用) / quote(原作実在の言い回しのみ) / skill / tone(口調メモ)`。
4. 画像が無い場合は自動でシルエット＋名前プレートにフォールバックし、コンソールに不足一覧が出る（停止しない）。
5. 語録は `data/quotes.json` に追加: `text(全角24字以内) / type(honshitsu・a_honshitsu・noise・fake_katsu・rare) / speaker / source(○年生編・第○章) / weight / unlocked`。
