# ✝本質✝ OVERFLOW ―偏差値60の教室から―

原作 `gensaku.txt` の語録と、リポジトリに入っていた立ち絵・アイコンを使った、60秒固定のスコアアタックです。ビルド不要・相対パスのみで、GitHub Pages に置いて `index.html` を開けば遊べます。

## 遊び方

1. タイトルの「TAP TO 漏出開始」を押す。チュートリアルは4秒、タップでもスキップできます。
2. 一番下に来たカードだけが判定対象です。白紙＋金の縁＋✝は **刻む**、灰色の亜✝本質✝・赤茶のまとめサイト風カード・フェイカツは **は？**。
3. 刻むはタップ / `Z` / `←`、は？は下スワイプ / `X` / `→`。スマホは画面下の2ボタンも使えます。
4. OVERFLOW が100%になったら、好きな密度の瞬間に `Space` または下部の `✝ Space` を押します。7秒間、時間が止まり、全カードが本質化します。
5. 60秒終了後、結果画面をタップすると演出をスキップできます。ローカルハイスコア・語録・掲示板レス番号は `localStorage` に保存されます。

右上の「音 ON」でWeb Audio合成音を切り替えられます。初回入力までAudioContextは開始しません。

## スコア計算

```text
倍率 = min(8, 1 + floor(combo / 10) × 0.5)
       ※ 数理零ライン発動中は上限10、OVERFLOW中は +2
刻む成功 = 100 × 倍率
は？成功 = 60 × 倍率
コーンスープ = 700 × 倍率、残り時間 +3.0秒
結婚指輪 = 1500 × 倍率、残り時間 +0.8秒
英語カード = 900 × 倍率、残り時間 +5.0秒
誤爆 = 残り時間 -1.50秒、コンボ0、倍率リセット、OVERFLOW 30%減
本質取りこぼし = 残り時間 -0.50秒
偏差値 = 60 + 40 × (1 - exp(-score / 45000))
```

## 体感調整の3案

- **もっと簡単に**：`SPAWN.*.speed` を全区間0.85倍、`SPAWN.*.interval` を+0.12秒、`SCORE.errorTime` を1.1秒にする。見極めの時間を増やし、誤爆の圧を落とせます。
- **もっと忙しく**：30秒以降の`simultaneous`を+1、`SPAWN.rush.interval`を0.34秒、ノイズ率を+0.06。前半の気持ちよさは残したまま終盤だけ密度を上げます。
- **ハイスコア狙いを強く**：`OVERFLOW.fillPerHit`を0.10に落とし、`MULTIPLIER.comboAdd`を0.6に、`OVERFLOW.seconds`を6秒にする。ゲージの発動判断とコンボ維持の差が広がります。

## アセット追加手順

- 立ち絵（透過PNG）をリポジトリ直下または`assets/`に置き、`data/characters.json` の `standing` を相対パスで更新します。
- アイコンは `data/characters.json` の `icon` を更新します。現在の画像は原作同梱の `icon/` と処理済み立ち絵をそのまま参照しています。
- ファイルが見つからない場合はゲームを停止せず、DOMの`img`が空のキャラバッジとして残ります。コンソールに不足アセットを出す設計です。
- 語録は原作に実在する言い回しだけを `data/quotes.json` に追加してください。表示文は全角24文字以内、`source` に編・章、`weight` と`unlocked`を設定します。

## デバッグ

`index.html?debug=1` で、FPS・状態・現在の速度係数・ランクスライダー・ゲージ満タン・原✝本質✝召喚・即TIMEUPを表示します。ヒットボックスはカード最前面の円とカード外形で常時確認できます。

## 実装メモ

- 背景・ゲーム・加算エフェクトを3枚のCanvasに分離し、HUD・結果・コレクションをDOMで構成。
- カードと粒子は固定プールを再利用。可変フレームレートは`deltaTime`基準、復帰時のデルタは50msにクランプ。
- `prefers-reduced-motion`時はシェイク停止、粒子量を落とし、ゲーム判定は変えません。
- Web Audioはノイズ・オシレーター・フィルターだけでSE/BGMを合成し、音声ファイルは使っていません。
