# ✝本質✝スコアアタック

原作 **「偏差値60の教室から✝本質✝が漏れ出している件について」**（`gensaku.txt` 全4021行・一年生編／二年生編／三年生編一学期）を精読してスコアを競う、**制限時間つきのスコアアタック**です。パズル要素はありません。読んだ者だけが答えられる問題に、時間を削られながら即答し続けます。

## 遊び方（起動）

`game/` は完全な静的サイトです。ビルド不要。

```bash
# リポジトリ直下で
python3 -m http.server 8000 --directory game
# → http://localhost:8000/
```

`game/index.html` を直接ブラウザで開いても遊べます（画像は相対パス参照）。

### モード（3種）

| モード | 制限時間 | 内容 |
|---|---|---|
| ⏳ **本質サバイバル** | 90秒 | 全タイプの精読問題をミックス。**誤答 −3秒**。時間が0で終了 |
| 💬 **「は？」ラッシュ** | 60秒 | 1問4秒の即答戦。セリフ当て・本物／フェイカツ判定・二択のみ。未回答も誤答扱い（−3秒） |
| 🎯 **大喜利「本質を一言で」** | 45秒 | 伊豆見主催の大喜利大会。ウケた回答で**+2秒**、誤答で**−2秒** |

### ルール

- 時間は常に減り続けます（解答後の解説表示中のみ停止）。
- 得点 = 難易度（100／200／300点）＋**速さボーナス（最大+50%）**、さらに**コンボ倍率（×1.0〜×3.0）**、残り10秒以下は**ラストスパート ×1.5**。
- 8問正解ごとに**「✝本質✝募集所」配信イベント**が挟まり、+250点と小休止。
- 終了時、得点に応じた**称号**（非✝本質✝ 〜 ✝本質✝そのもの）と、登場人物からの一言が出ます。
- 名前を入れて端末内ランキング（localStorage）に登録できます。

### 操作

タップ／クリック、またはキーボード（`1`〜`4`、二択は `←`／`→`）。本物 vs フェイカツ問題は**左右スワイプ**でも判定できます。`Enter`/クリックで解説を早送り、`Esc` でタイトル、`R` でリトライ。

## 出題について

`game/js/data.js` に **117問** の問題データベースを収録（すべて `gensaku.txt` の記述由来・出典章つき）。

- **原作知識4択**（味噌の地政学／河岸段丘／異棟合同課題／翠湖十キロ／球技大会 二点差 など）
- **数字4択**（倉石の「✝本質✝年鑑」速報値、視聴者数、切り抜き再生数 など）
- **セリフ当て**（この台詞は誰？ 顔アイコンつき4択）
- **本物 or フェイカツ**（原作に実在する文章か、改変された偽物かを直感で仕分ける）
- **✝本質✝判定**（その出来事は✝本質✝か、そうでないか）
- **大喜利**（一番ウケた回答を当てる）

「〜じゃない」形式の問題は、**原作に実在するかどうか**が判定基準です。誤答後は必ず出典章と解説が出るので、原作を読み返す導線になります。

## 素材

- 立ち絵・顔アイコン：リポジトリ内の `chr_*.png` / `processed_chr_*.png` / `icon/*.jpg` を WebP に変換して使用（`game/assets/`）。
- 背景：教室・地形図の2点を生成し `game/assets/bg_*.webp` として同梱。CSS側で低不透明度のテクスチャとして重ねています。
- 音：`game/js/audio.js` が WebAudio でその場で合成（チップチューンBGM＋効果音）。音声ファイルは不要です。

## 構成

```
game/
├── index.html          画面（タイトル／カウントダウン／プレイ／リザルト／ランキング／遊び方／登場人物）
├── css/style.css       スタイル（地形図・紙モチーフ、コンボやペナルティの演出）
├── js/data.js          キャラ15名＋問題117問＋称号＋配信ネタ（原作準拠）
├── js/audio.js         WebAudio 効果音・BGM
├── js/game.js          出題ロジック／タイマー／判定／スコア／演出／ランキング
└── assets/             faces（顔アイコン）／chara（立ち絵）／背景
```

非公式のファン制作物です。原作テキストは `gensaku.txt` を参照してください。
