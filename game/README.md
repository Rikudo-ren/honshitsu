# ✝本質✝ RUSH — 偏差値60の教室から

『偏差値60の教室から✝本質✝が漏れ出している件について』（`../gensaku.txt`）のキャラクターを
総動員した **60秒スコアアタック・アクション**。パズル要素なし、制限時間内でハイスコアを競う。

## 遊び方

```
python3 -m http.server 8080   # このディレクトリで
# → http://localhost:8080
```

- **移動**: ←→ / AD / マウス移動　**射撃**: 自動連射
- **✝本質解放✝**: ゲージ100%で SPACE / タップ（画面一掃＋無敵）
- **P**: ポーズ

### ルール

| 要素 | 効果 |
|---|---|
| 偏差値ブロック（30–80） | 撃破で 数値×2 pt（数値が高いほど硬い） |
| 模試順位表 | 耐久3、150 pt |
| ✝本質 | 300 pt＋ゲージ+25（速い） |
| コーンスープ | 100 pt＋**+2秒**（補充された） |
| 敵に当たる | **-3秒＆コンボ消滅**（本質難易度なら-5秒） |
| 強敵（キャラ顔面） | 20秒・45秒に出現。撃破で800/1200 pt＋+3秒 |

連続撃破でコンボ倍率最大×5。キャラ14人はそれぞれ 速/射/力/運 のステータスが異なる。
ハイスコア8位まで localStorage に保存。

## 開発

```
node game/test.js    # 純粋ロジック(logic.js)のテスト — 11 cases
node game/smoke.js   # ブラウザシェル(main.js)をスタブDOMで1ラウンド完走させるスモークテスト
```

`logic.js` は DOM 非依存の純粋ロジック（ブラウザとNodeで共有）。
`main.js` は描画・入力・音(WebAudio)・ランキング担当。
スプライト/顔画像は `assets/` にリポジトリ既存PNG/JPGから縮小生成済み。
