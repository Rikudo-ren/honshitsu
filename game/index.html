🏆 スコアランキング

📖 遊び方

基本

  • 画面に出る問題に、タップ／クリック／キーボード（1〜4、←→）で即答する制限時間つきスコアアタックです。
  • 時間は止まりません。誤答すると −3秒。時間が0になった時点で終了。
  • 解答後の解説表示中だけ、時間が止まります（精読ポイントを読む時間）。

スコア

  • 基本点 = 難易度（100 / 200 / 300点）。
  • 速さボーナス：早く答えるほど最大 +50%。
  • コンボ倍率：連続正解で ×1.0 → ×3.0 まで上昇。誤答でリセット。
  • ラストスパート：残り10秒を切ると全得点 ×1.5。
  • 8問ごとに「本質配信」演出が挟まり、休憩＆+250点。

モード

  • 本質サバイバル：90秒。誤答 −3秒。全タイプの精読問題。
  • 「は？」ラッシュ：60秒。1問4秒の即答戦。速さで殴り合う。
  • 大喜利：45秒。正解すると +2秒、誤答 −2秒。ウケた回答を選べ。

出題について

原作（gensaku.txt 全4021行）の記述から作成した123問超のデータベースを使用。セリフ当て・数字当て・本物／フェイカツ判定などをランダムに出題します。「〜じゃない」問題では、原作に実在する発言かどうかが判定基準です。
